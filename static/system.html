Why this page exists

For export reviewers: machine context for Framework #146 and similar power-cap reports. framelog ties throttle samples to dGPU runtime, PMF limits, charger/profile context, and journal messages. Storage serial numbers are omitted.

CPU fields

  • Model / Vendor from procfs.
  • Logical CPUs and Physical cores for capacity context.
  • Max MHz from cpufreq when exposed (not a live sample).

GPU fields

  • Card — DRM names such as card0.
  • PCI, Vendor ID, Device ID identify the sampled GPU.
  • Driver — expected kernel driver for the device.

Interpreting #146

  • Persistent SPL, STAPM, or PROCHOT_CPU with capped APU power.
  • Correlate with dGPU runtime suspend / D3cold state.
  • Check pmf.spl_mw, sppt_mw, STT skin temps at the same timestamps.

Data sources

  • CPU/OS: /proc, /etc/os-release.
  • GPU, BIOS, memory, storage: read-only /sys.
  • Live refresh: POST /api/system/refresh; exports embed the latest snapshot.
